# MessageStar 官方 APK 下载

本仓库仅提供 MessageStar 的正式签名 APK 和 `update.json` 更新清单。公开源码在 [zcohlaz/message-star](https://github.com/zcohlaz/message-star)；签名密钥不公开。

从 [Releases](https://github.com/zcohlaz/message-star-updates/releases) 下载最新的 `MessageStar-v*.apk`。Android 8.0 及以上设备打开 APK 后，按系统提示允许安装并确认。使用同一正式签名覆盖安装时，原有应用数据会保留；无需先卸载旧版。

v1.1.0 及更早版本尚无应用内更新功能；v1.2.0 在部分网络下无法连接旧清单地址。这些版本建议从本页手动安装一次 v1.2.1。此后可在 App 的“设置 → 检查更新”中查询新版本，系统仍会要求用户确认安装。`update.json` 包含版本号、更新说明、文件大小与 SHA-256 校验值。

如系统提示签名不匹配，请停止安装，不要通过卸载旧版来绕过提示；先确认下载的是本仓库发布的正式 APK。
